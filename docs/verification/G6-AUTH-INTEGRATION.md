## 已实现

- `shared/auth-client`：纯Java认证消费库，预约/维修服务共用；每次请求内省，无成功身份缓存、无JSESSIONID持久认证、无重定向或应用层重试。
- `ApiAccessRule`显式方法/路径/模块/动作登记；未登记路径继续拒绝。粗粒度动作门禁之后，对象范围、本人归属及回避规则仍由对应owner实现。
- G5-I01兼容扩展requestMethod/csrfToken，同一只读快照内验证当前会话、CSRF和身份；原仅sessionToken请求仍能读身份。请求对象保持凭据脱敏，明确区分缺失与null字段。
- G5响应严格按Principal解析，版本号保持字符串，scope/身份投影不可变；超时、错误服务凭据、畸形/超大响应均失败关闭。
- Compose和环境脚本增加四个独立模块凭据。旧.env只追加缺失key，不覆盖数据库密码、已有token；没有新增业务迁移。
- 增加真实三服务验收模块和CI作业，并纳入bootstrap-required；Docker构建已补共享库及测试POM接入。
- 同步G5 OpenAPI、完整示例、技术文档、README、接入说明、决策和任务记录。
