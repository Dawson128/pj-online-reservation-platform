# 审批服务迁移

首次建表、新增迁移、运行权限和验收流程见 [数据库建表与迁移指南](../README.md)；当前 G5 表用途见 [G5 表清单](g5/README.md#现有应用表清单)。

`g2/` 和 `g5/` 分别由对应组维护。审批服务统一打包此目录至 `classpath:db/migration`，由同一个 Flyway 实例递归发现两组迁移，使用 `m2.flyway_schema_history`。

G5-002 已新增账户、院系、角色、权限、角色绑定、会话、限速及审计/outbox 结构迁移。Flyway 负责结构，应用中的幂等种子负责权限/角色和显式启用的初始管理员。不在 SQL 中写入默认密码或真实凭据。

后续迁移遵守根目录 AGENTS.md 的命名、归属和不可变规则。README 仅说明约定，不由 Flyway 作为 SQL 执行。
